2. 运行手册

2.1 开发模式（四步走）

npm install
npm run core          # Core 守护进程（初始化 SQLite + 随机 starter pet）
npm run desktop       # Electron 桌宠窗（或 npm run ui 浏览器预览 127.0.0.1:5173）
npm run sim -- --scenario multi_session   # 试玩：注入 3 session 并行

2.2 打包版（.app 双击即用）

npm run dist:mac      # 产出 dist/Vibepaws.app（自动拉起 Core + UI，无需手动 npm run core）

打包版日志在 ~/Library/Application Support/Vibepaws/vibepaws.log；数据在 userData/.vibepaws。

2.3 接入真实 agent

# Claude Code
npm run adapter:install -- --agent claude_code   # 写 .claude/settings.json（含 statusLine，实时 token）
# Codex
npm run adapter:install -- --agent codex         # 写 .codex/hooks.json + 自动配置项目信任
#   hooks 信任注册（首次生效，二选一）：
#   ① 交互：cd 项目 && codex，运行 /hooks 批准
#   ② 自动化：codex exec --dangerously-bypass-hook-trust …

3. token 采集机制（2026-08 新增）

已落地调研结论：Claude Code / Codex 的 hooks stdin 均不含 token 字段（实测 + 源码确认）。token 经以下通道获取：

通道机制状态
Claude Code statusLinesettings.json 配 statusLine.command；每次状态刷新 stdin JSON 含 context_window.total_input_tokens/total_output_tokens（官方口径：input 含缓存读写）；headless -p 不触发（TUI 特性）实时
Claude Code SessionEndhook 输入带 transcript_path → 解析 assistant message.usage（input+output+cache_creation）→ 一次性 token_update兜底 实测 53218 tokens
Codex SessionEndtranscript_path → ~/.codex/sessions/*.jsonl（session 存档）；提取逻辑通用，格式不符自动降级best-effort

数据流：token_update → sessions.token_used → EXP token 奖励（1000 tokens = 1 EXP × context/topic 倍率，daily cap 200）。

4. Codex 接入要点（实测踩坑）

坑原因解决
hooks 不执行Codex v0.148 项目级 hooks 被「项目信任」门控（未信任 → 项目层 disabled）install.ts 自动写 ~/.codex/config.toml 的 projects 信任（带备份）
hooks 事件键一度误判为蛇形（session_start）源码 #[serde(rename = "SessionStart")] 确认驼峰，与 Claude Code 一致
hooks 信任非托管 hooks 需审查否则被跳过/hooks 交互 或 --dangerously-bypass-hook-trust
token 缺失codex hooks 无 usage 字段、无 statusline（0.148）SessionEnd 读 session 存档（best-effort）

5. 隐私与安全

  • 双闸：adapter 白名单提取（丢弃 tool_input/prompt/transcript_path）→ Core 落库前 schema 丢弃未知字段；原始 hook JSON 永不落库
  • token 提取：只读数字（input/output/cache tokens），不读代码/文本内容
  • 传输：本地 127.0.0.1 + API token（双写 cwd/.vibepaws 与 ~/.vibepaws，任意 cwd 的 hook 可认证）
  • 数据：删除 = 清空 .vibepaws 数据目录
